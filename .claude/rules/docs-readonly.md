# 과제 문서 취급

- 제출본(파일명에 제출일이 있는 계획서, 연차보고서, 공고, RFP, 공문)은 수정·이동·이름 변경하지 않는다.
- 같은 항목이 문서 판마다 다르다. 기준 순서: 3차년도 수정사업계획서(2026-05-15) > 2차년도 수정사업계획서 > 협약용 계획서.
  2차 연차보고서 5-5의 3차년도 예산은 감액 전 수치다.
- 공고와 RFP 파일은 확장자만 PDF이고 실제로는 이미지와 OCR 텍스트 묶음(zip)이다. 표는 이미지와 대조한다.
- 문서 표지와 7장의 연락처, 인건비 현황표는 인용하지 않는다.
- 인용할 때 문서명, 판(제출일), 위치를 함께 적는다.
