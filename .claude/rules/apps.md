# 앱 공통

- 스키마와 코드리스트는 `shared/standard-model/`에서 읽는다. 앱 안에 복사본을 커밋하지 않는다.
- 비밀값은 `.env`(git 제외)에서 읽고 `.env.example`에 키 이름만 둔다. IDS 인증서·키는 저장소 밖 경로를 환경변수로 받는다.
- KR-GEARs와 IDS 서버는 실제 운영 시스템이다. 테스트에서 호출하지 않는다. 모의 서버나 녹화된 합성 응답을 쓴다.
- `kr-ghg-ai-agent`: 매핑과 수치 계산은 결정적 코드로 하고, LLM은 미매핑 항목의 후보 제안과 설명에만 쓴다.
  LLM이 제안한 매핑은 검증 스킬을 통과하고 사람이 승인하기 전에는 전달 경로에 넣지 않는다.
- OAuth 2.0과 TLS는 설계에 반영하되 본 과제에서는 적용하지 않는다(2차 연차보고서). 적용한 것처럼 문서에 쓰지 않는다.
