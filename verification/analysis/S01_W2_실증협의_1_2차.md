## 3. KR GHG 시나리오(안) (KR pptx s.2)
BLOCK A(랩오투원): 선박 시뮬레이터(Sensor/AMS/VDR Log) →운항/배출 로그→ ROC(RIMS) →표준 JSON/API→ IDS Provider Dataset. 매핑 기준: IMO Compendium, ISO 19848, 코드북/샘플데이터. 증빙: Provider API 요청·응답, Dataset 등록, 변환 로그.
