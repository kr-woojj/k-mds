## 3. 유엔젤 통합테스트 판정 기준 (C p.11-12)
IDS RAM 절차: Self-Description(Connector→Broker) → Catalog(DCAT 메타 등록) → Discovery → Contract Negotiation → DAPS 토큰 → mTLS Handshake → Data Transfer → 로깅·감사. "판정 기준: 각 단계 응답 정상 + 전체 데이터 정합율 95% 이상". 2차 테스트: "정합율 95% 이상 + 인증·계약 절차 정상 → 설계서 v1.0". 성능지표 #4 정합율 2차 90(자체평가) / 3차 95(전문가평가). H p.97: 정합율은 "데이터 등록→검색→요청→승인→전송 단위 프로세스별 성공률" — 수치 산식 문서 근거 없음.
